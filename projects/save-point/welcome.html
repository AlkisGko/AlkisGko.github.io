OBJECTIVE

Make the first email useful.

Introduce the wishlist service, explain the three-step value proposition and invite new players to save their first game.

AUDIENCE & TRIGGER

Designed for newly registered, opted-in customers. The welcome creative was built and tested with sample customer records in Salesforce Marketing Cloud Playground; the full automated journey is a future phase of this fictional project.

PERSONALISATION

Looks up the first name by email address, formats it with ProperCase(), and greets customers without a name as “Adventurer”.

02 / DESIGN & LOGIC

A few decisions behind the build.

01

Personal, not fragile

A Customers Data Extension supplies the first name through AMPscript. Missing names have a deliberate “Adventurer” fallback, so personalisation never results in an awkward blank greeting.

02

Built for reuse

The SAVE POINT header and footer are separate Content Builder blocks. They keep campaign branding consistent and make future journey emails easier to maintain.

03

Email-client reality

Table-based layout and inline CSS prioritise compatibility, including an Outlook-specific fixed-width wrapper. The three feature columns stack on narrow mobile screens.

04

One clear next step

“Start your wishlist” appears before and after the how-it-works explanation: one CTA for readers who are ready immediately, and one for those who need context.

05

Creative with a purpose

The illustrated quest motif makes the steps approachable without hiding the product benefit: save games, let SAVE POINT monitor prices, and hear about worthwhile deals.

06

Readable by design

Image alternative text, a hidden preheader and carefully chosen text colours make the email understandable beyond its decorative artwork.

03 / UNDER THE HOOD

The interesting bits.

The most useful piece of logic is the first-name lookup and its fallback. Everything else in the email is designed around robust HTML rendering and reusable components.

AMPscript / HTMLFirst-name lookup with fallback
%%[
  VAR @name, @email
  SET @email = AttributeValue("EmailAddress")
  SET @name = Lookup("Customers", "First_Name", "Email", @email)
  SET @name = ProperCase(@name)
  IF Empty(@name) THEN
    SET @name = "Adventurer"
  ENDIF
]%%

<p>Hey %%=v(@name)=%%!</p>

Implementation note: The original email uses two reusable SFMC Content Builder blocks (header and footer), plus AMPscript that runs when the email is rendered in Salesforce Marketing Cloud.

AMPscript runs in Salesforce Marketing Cloud, so the portfolio preview will show an example output rather than execute AMPscript in the browser.
