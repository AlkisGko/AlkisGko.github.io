OBJECTIVE

Make the first email useful.

Introduce the wishlist service, explain the three-step value proposition and invite new players to save their first game.

AUDIENCE & TRIGGER

Intended for newly registered, opted-in customers. Sonya is a fictional sample recipient used to demonstrate the creative. The audience selection, trigger and automated journey are proposed rather than deployed.

PERSONALISATION

The AMPscript is written to look up a first name by email address, format it with ProperCase(), and use “Adventurer” when no name is available.

02 / DESIGN & LOGIC

A few decisions behind the build.

01

Personal, not fragile

The AMPscript is designed to retrieve a first name from a Customers data table. Missing names have a deliberate “Adventurer” fallback, avoiding an awkward blank greeting.

02

Built for reuse

The template references separate header and footer content blocks to keep branding consistent and make future journey emails easier to maintain.

03

Email-client reality

Table-based layout and inline CSS prioritise compatibility, including an Outlook-specific fixed-width wrapper. The three feature columns stack on narrow mobile screens.

04

One clear next step

“Start your wishlist” appears before and after the how-it-works explanation: one CTA for readers who are ready immediately, and one for those who need context.

05

Creative with a purpose

The illustrated quest motif makes the steps approachable without hiding the product benefit: save games, let SAVE POINT monitor prices, and hear about worthwhile deals.

06

Readable by design

Image alternative text, a hidden preheader and carefully chosen text colours make the email understandable beyond its decorative artwork.

03 / UNDER THE HOOD

The interesting bits.

The key personalisation example is the first-name lookup and its fallback. The layout also demonstrates table-based email HTML and reusable components.

AMPscript / HTMLFirst-name lookup with fallback
%%[
  VAR @name, @email
  SET @email = AttributeValue("EmailAddress")
  SET @name = Lookup("Customers", "First_Name", "Email", @email)
  SET @name = ProperCase(@name)
  IF Empty(@name) THEN
    SET @name = "Adventurer"
  ENDIF
]%%

<p>Hey %%=v(@name)=%%!</p>
